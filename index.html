ID DM Collector 개인정보처리방침

최종 업데이트: 2026-10-02

ID DM Collector(이하 “앱”)는 사용자가 본인의 Instagram 계정에서 직접 사용하는 개인용 데스크톱 도구입니다. 이 앱은 사용자가 명시적으로 연결한 Instagram Professional 계정의 메시지 이벤트를 Meta의 Instagram API 및 Webhook을 통해 처리하여, 사용자가 직접 보낸 Instagram 게시물 또는 릴스 링크를 로컬 컴퓨터에서 정리하거나 다운로드할 수 있도록 돕습니다.

1. 수집 및 처리하는 정보

앱은 기능 제공을 위해 다음 정보를 처리할 수 있습니다.

  • 연결된 Instagram 계정의 기본 식별 정보
  • Instagram Direct 메시지 및 메시지 이벤트 정보
  • 메시지에 포함된 Instagram 게시물 또는 릴스 링크
  • Instagram API 액세스 토큰 및 앱 설정값

2. 정보 이용 목적

처리된 정보는 다음 목적에만 사용됩니다.

  • 사용자가 직접 보낸 Instagram 콘텐츠 링크 감지
  • 해당 콘텐츠의 제작자 또는 게시물 정보 확인
  • 사용자가 선택한 콘텐츠의 로컬 저장 및 중복 다운로드 방지
  • 앱의 정상 작동을 위한 Webhook 검증 및 API 요청

3. 저장 위치 및 보관

앱의 설정과 처리 기록은 사용자의 로컬 컴퓨터에 저장됩니다. 앱 개발자가 별도의 원격 서버에 사용자의 Instagram 메시지 내용이나 다운로드 파일을 저장하는 것을 목적으로 하지 않습니다.

Meta Webhook 연결을 위해 Cloudflare Tunnel과 같은 HTTPS 터널 서비스가 사용될 수 있으며, 이는 외부 요청을 사용자의 로컬 앱으로 전달하기 위한 통신 경로로 사용됩니다.

4. 제3자 제공

앱은 사용자의 정보를 광고 목적이나 판매 목적으로 제3자에게 제공하지 않습니다. 다만 기능 수행 과정에서 Meta Platforms의 Instagram API 및 사용자가 직접 선택한 네트워크/터널 서비스가 사용될 수 있습니다.

5. 보안

앱은 Webhook 요청 검증과 로컬 처리 방식을 사용합니다. 사용자는 액세스 토큰, 앱 시크릿 등 인증 정보를 다른 사람과 공유하지 않아야 합니다.

6. 사용자 데이터 삭제

사용자는 앱의 로컬 설정 파일과 다운로드 기록 파일을 직접 삭제하여 저장된 로컬 정보를 제거할 수 있습니다. 또한 Instagram의 “앱 및 웹사이트” 설정에서 앱의 접근 권한을 해제할 수 있습니다.

7. 정책 변경

앱의 기능 또는 Meta API 요구사항이 변경되는 경우 본 개인정보처리방침도 변경될 수 있습니다.
